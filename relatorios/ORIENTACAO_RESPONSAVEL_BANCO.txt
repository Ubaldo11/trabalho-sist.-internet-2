4. CORRECAO OBRIGATORIA DA IMPORTACAO
------------------------------------------------------------

A validacao atual falhou durante o COPY da tabela aposentados com o erro:

null value in column "portaria_aposentadoria" violates not-null constraint

O CSV possui valores vazios validos nesse campo. Portanto, a coluna
portaria_aposentadoria NAO pode ser NOT NULL.

Tambem devem aceitar NULL, caso existam valores vazios:

- portaria_aposentadoria
- data_inatividade
- data_ingresso_servico_publico
- valor_aposentadoria

As demais colunas devem ser avaliadas conforme os dados reais antes de usar
NOT NULL. O importante e nao rejeitar registros validos por causa de campos
opcionais vazios.

No COPY, manter o tratamento de vazio como NULL:

WITH (FORMAT csv, HEADER true, DELIMITER ';', NULL '')

Depois da correcao, destruir o volume de teste e criar um volume novo para
validar a inicializacao desde o zero. Volumes antigos nao executam novamente
os scripts de /docker-entrypoint-initdb.d.

------------------------------------------------------------
5. INDICES OBRIGATORIOS PELO ENUNCIADO
------------------------------------------------------------

O enunciado exige consultas por:

- nome exato;
- nome similar;
- cargo ou profissao;
- estado/UF;
- instituicao/orgao;
- combinacao de filtros.

Por isso, criar os seguintes indices:

5.1 Tabela aposentados

- indice para nome, preferencialmente GIN com pg_trgm para similaridade;
- indice para cargo_emprego;
- indice para orgao;
- indice para cpf, se usado para identificacao;
- indice para matricula, se usado nas consultas.

Exemplo:

CREATE EXTENSION IF NOT EXISTS pg_trgm;

CREATE INDEX aposentados_nome_trgm_idx
    ON aposentados USING GIN (nome gin_trgm_ops);

CREATE INDEX aposentados_cargo_idx
    ON aposentados (cargo_emprego);

CREATE INDEX aposentados_orgao_idx
    ON aposentados (orgao);

CREATE INDEX aposentados_cpf_idx
    ON aposentados (cpf);

5.2 Tabela carreiras

- indice para nome, preferencialmente GIN com pg_trgm para similaridade;
- indice para cargo_emprego;
- indice para uf;
- indice para orgao;
- indice para cpf, se usado para identificacao.

Exemplo:

CREATE INDEX carreiras_nome_trgm_idx
    ON carreiras USING GIN (nome gin_trgm_ops);

CREATE INDEX carreiras_cargo_idx
    ON carreiras (cargo_emprego);

CREATE INDEX carreiras_uf_idx
    ON carreiras (uf);

CREATE INDEX carreiras_orgao_idx
    ON carreiras (orgao);

CREATE INDEX carreiras_cpf_idx
    ON carreiras (cpf);

Os indices de nome com pg_trgm sao necessarios para as buscas por
similaridade solicitadas no enunciado. Os indices de cargo, UF e orgao
atendem as buscas simples e ajudam nas buscas combinadas.

7. TESTE MINIMO DO RESPONSAVEL PELO BANCO
------------------------------------------------------------

A partir da pasta projeto:

1. Construir a imagem:

   docker compose build db-server

2. Remover somente o volume local de teste, se existir:

   docker compose down -v

3. Inicializar o banco:

   docker compose up -d db-server

4. Conferir a saude do servico:

   docker compose ps db-server

5. Conferir contagens e indices com psql dentro do container.

A porta 5432 pode estar ocupada por outro PostgreSQL local. Nesse caso,
validar o container sem publicar a porta ou parar o processo que ocupa a
porta. Nao alterar os nomes internos do banco, usuario ou servico.
